# 🎄 圣诞小岛 · Christmas Island 🏝️

> 一座会下雪的海上小岛，把你的心愿挂到树上 ✨

---

## 🌟 这是什么？

一个**打开就能玩**的 3D 圣诞小岛网页 🎅
不需要注册、不需要服务器、不需要配置，双击 `christmas-wall.html` 就能进岛 🚀

岛上有一座挂满心愿彩球的圣诞树 🌲、六间可以点开的小铺 🍪🍷🪆🍦🧣🎁、一个花样滑冰场 ⛸️、一个 K 歌舞台 🎤、一架会把你甩起来的飞椅 🎠、一头拉着雪橇的麋鹿 🦌，还有一个能拍四宫格的复古照片亭 📷！

---

## 🕹️ 怎么玩

| 想做的事 | 怎么点 |
| --- | --- |
| ✍️ 写心愿 | 底栏「写心愿」→ 写完挂到树上 → 还能存成图片 💾 |
| 💌 抽一句暖心话 | 底栏「暖心话」→ 抽到喜欢的就挂树上 |
| 🎪 逛小铺 | 点街上任意一间铺子，会弹出插画小卡片 |
| ⛸️ 看花样滑冰 | 点冰场 →「看一场完整表演」 |
| 🎤 唱一首 | 点 K 歌舞台 → 选歌 → 还能开麦打分 |
| 🎠 坐飞椅 | 点飞椅，镜头会跟着一起转（有点晕哦 😵） |
| 🦌 乘雪橇 | 点雪橇，麋鹿带你绕岛跑一圈 |
| 📷 拍四宫格 | 点照片亭 → 选「和圣诞老人拍」或「前置摄像头自拍」→ 4 张 → 一张复古四宫格 |
| 🏝 看全岛 | 右上角「看全岛」，一次看到整座岛 |
| 🌙 换天色 | 右上角「天色 · 天气」，6 种天色 × 4 种天气 |

> 🖱️ 拖动转视角 · 滚轮/双指缩放 · ⌨️ `Esc` 关弹窗 · `←` `→` 翻心愿

## 🎨 岛上有什么

- 🎄 **一棵大圣诞树**：暖光灯珠、玻璃彩球、小金星、螺旋星河、飘落光屑，树顶是会转的星芒
- 🏠 **六间小铺**：蜜糖姜饼铺、热红酒与肉桂、套娃工坊、雪夜冰淇淋、毛线铺子、礼物盲盒
- ⛸️ **溜冰场**：9 位市民慢慢滑，还有一位选手表演燕式步、阿克塞尔跳、贝尔曼旋转
- 🎤 **K 歌舞台**：4 首公版圣诞颂歌 + 歌词大屏 + 会跟着节拍跳动的舞池
- 🎠 **红场飞椅**：12 把彩色座椅，转起来会把座椅甩出去
- 🦌 **麋鹿雪橇**：红鼻子的麋鹿绕岛一圈，避开所有房子
- 📷 **复古照片亭**：两种拍法——圣诞老人连做 4 个动作（招手 / 欢呼 / 比耶 / 张开手），或者打开前置摄像头自拍 4 张（会提示你比耶、笑、眨眼、比心），出图都是米色相纸的四宫格
- 🌌 **天空彩蛋**：银河、流星、极光、孔明灯、浮空小岛、天上飞的圣诞老人雪橇

## 💌 关于心愿

- 心愿**只存在你自己的浏览器里** 🏠，不会上传到任何服务器，也不会被别人看到
- 第一次打开岛上已经有 8 条别人留下的暖心话（只是初始内容）
- 每张心愿卡都能**保存成 PNG 图片** 📥，发朋友圈刚刚好
- 想清空重来：浏览器设置里清掉这个页面的网站数据即可 🧹

---

## 🚀 怎么打开

1. 双击 `christmas-wall.html`（电脑上的 Chrome / Edge / Safari 都行）
2. 想发给朋友：把这个文件传到任意静态托管（GitHub Pages、Vercel 等），得到一个 https 链接
3. 页面会从 CDN 加载 3D 组件（three.js）。如果一直停在加载页，会出现提示，点「换镜像重新加载」即可 🔁

> 📱 手机上也能玩，只是旧机型可能会有点烫 🥵

---

## 🧩 小提示

- 🎧 K 歌和铃铛需要开声音
- 🎤 麦克风打分只在 https 网页里可用（本地双击打开点不了）
- 🌬 暴风雪天气会遮挡视线，想看清远处就切回「晴朗」
- 🔍 卡顿时可以切到「晴朗」+ 少走几步，场景会轻一些

- 手写的光点雪、星河、极光、海面着色器 🌊
